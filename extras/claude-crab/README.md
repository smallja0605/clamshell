# Claude Crab

<p align="center"><img src="preview.gif" alt="The Claude Code crab in the menu bar" width="346"></p>

The pixel crab used by Claude Code, as a Clamshell mascot pack.

- **Install:** double-click [`ClaudeCrab.clamshellmascot`](ClaudeCrab.clamshellmascot) with Clamshell installed — it appears under
  *Mascot* in the menu. Or build the app with `./scripts/build-app.sh --with-extras` to ship it inside the app.

- **Preview:** `preview.gif` is generated by Clamshell itself (`tools/make_preview.sh`), not a recording of anyone's screen.

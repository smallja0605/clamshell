# Claude Crab (optional extra)

This folder holds a mascot pack of the pixel crab used by Claude Code.

**It is not part of Clamshell's MIT-licensed code.** The character is not an original work of this project, the
project's authors do not own it, and including it here does not grant anyone any rights to it. Clamshell is not
affiliated with, endorsed by, or sponsored by Anthropic; "Claude" and "Claude Code" are trademarks of Anthropic.

- Clamshell works fully without this pack. The default build does **not** include it.
- If the character's owner asks for it to be removed, deleting this folder is all that is needed.
- If you use or redistribute it, make sure you are allowed to.

To use it, either double-click `ClaudeCrab.clamshellmascot` (Clamshell installs it into its mascot menu), or build the app
with `./scripts/build-app.sh --with-extras`.

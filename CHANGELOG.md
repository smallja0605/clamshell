# Changelog

## 0.1.0 — unreleased
First version: a small crab lives in the menu bar while Claude Code works.

- Hidden while idle (or parked there with *Always show in menu bar*); crawls out of its neighbour when work starts and
  slips back when it ends.
- Opens its laptop once at the start, types while Claude works, closes it once at the end.
- Typewriter status text (Traditional Chinese or English), rolling label changes, rolling clock digits, animated "…".
- Session menu with project, git branch, state and elapsed time; click to bring the right terminal forward.
- Native hook helper (no Node.js needed); hooks installed only after the user agrees, with a backup.
- Mascots: import a GIF (menu, or drop it on the app icon), switch between mascot packs, export and share them as
  `.clamshellmascot` folders, command-line `--make-pack`.
- Optional completion chime, colour or black/white mascot, launch at login.
- Styled installer image.
